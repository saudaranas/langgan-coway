Daftar sebagai ejen Coway

Dapatkan link website sendiri. Prospek yang isi chat di link anda akan dihantar terus ke WhatsApp dan Telegram anda.

Prospek akan menghubungi anda di nombor ini.

Untuk terima notifikasi lead. Lihat di Telegram: Settings → Username.

Gambar ini dipaparkan pada popup promosi di link anda.

Pendaftaran diterima

Admin akan semak dan luluskan akaun anda. Sementara itu:

  1. Buka bot Telegram di bawah.
  2. Tekan START dan hantar "hi".
  3. Selepas diluluskan, anda akan terima link website anda di Telegram.
